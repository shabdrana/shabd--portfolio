# Shabd Rana — Portfolio

Static portfolio website ready for GitHub + Vercel.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a GitHub repository, e.g. `shabd-portfolio`.
2. Upload every file/folder in this project.
3. Import the repository into Vercel.
4. Framework preset: **Other** (or leave detected as static).
5. Deploy.

No build command is required.
